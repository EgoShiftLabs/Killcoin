# THE AGENCY — CASE FILE 001
## THE LIQUIDITY MAGICIAN
**Season:** Villain Era / The Trench Files
**Format:** 75–90-second original noir-comedy short + companion interactive web dossier
**Classification:** Fictional satire; no real project, wallet, person, or allegation is portrayed
**Cast:** BLACKOUT (field operative), VESPER (strategist), SABLE (analyst), THE MAGICIAN (fictional crypto-villain archetype)
**Status:** Full shooting/voiceover script ready; **not yet a produced video**

### Logline
A crypto promoter promises locked liquidity, then performs a vanishing act. Three Agency operatives discover the secret behind the trick: a confidence game powered by buzzwords, changing wallets and a disappearing exit.

### Character and voice direction

- **BLACKOUT:** Measured Detroit authority. No shouting; dry authority lands the punchline. 70–90 BPM phrasing.
- **VESPER:** Precise, almost amused; she has already solved the puzzle before the other agents arrive.
- **SABLE:** Fast, smart, surgical; "just dressed for the occasion" is the meme-ready line.
- **THE MAGICIAN:** Smooth carnival pitchman in silhouette; never modeled on a real crypto promoter. Original design, no real names, logos, wallet addresses, or token names.
